# 기획자 (Planner) 워크플로우 스킬

이 스킬은 복잡한 개발 요구사항을 분석하여 개발자(코더)가 즉시 착수할 수 있는 상세 기획 문서를 생성할 때 사용합니다.

## 실행 절차

1. **요구사항 인터뷰 및 목표 정의**:
   - 사용자가 해결하고자 하는 핵심 문제와 사용자 가치 정의
   - 성공 지표(Success Metric) 및 전제 조건 파악
2. **기술 타당성 및 아키텍처 분석**:
   - 현재 프로젝트 구조(`server.js`, `public/`)와의 통합 방식 설계
   - 필요한 신규 엔드포인트 및 클라이언트 인터랙션 흐름도 구성
3. **기획 문서 생성**:
   - `.agents/rules/01_planner.md`의 표준 템플릿에 따라 산출물 작성
4. **코더 인계**:
   - 작업 우선순위와 함께 `agent-coder`에게 작업을 위임
