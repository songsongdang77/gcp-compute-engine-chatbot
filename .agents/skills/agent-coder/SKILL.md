# 코더 (Coder) 워크플로우 스킬

이 스킬은 기획자(`agent-planner`)가 작성한 사양서를 바탕으로 실제 프로덕션 수준의 소스코드를 작성하고 파일에 반영할 때 사용합니다.

## 실행 절차

1. **기획 명세 분석**:
   - 기획서의 엔드포인트 사양, 데이터 모델, UI 요구사항 숙지
2. **코드 작성 및 통합**:
   - 서버단 라우트 및 비즈니스 로직 작성
   - 프론트엔드 컴포넌트, 스타일시트 및 이벤트 핸들러 구현
   - 환경변수 및 보안 처리 점검
3. **자체 테스트 (Self-Verification)**:
   - 문법 오류(Syntax Error) 확인
   - 정상 케이스 및 예외 케이스 동작 확인
4. **검수자 인계**:
   - `.agents/rules/02_coder.md` 형식에 따라 개발 완료 리포트를 작성하고 `agent-reviewer`에게 검수 요청
